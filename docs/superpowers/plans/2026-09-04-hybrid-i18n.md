# Hybrid Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add persistent English, Simplified Chinese, and Japanese UI selection without bulk-editing existing pages.

**Architecture:** `i18next` provides stable key-based translations for new UI. A bounded exact-text DOM bridge translates registered legacy chrome strings, including lazy and portaled nodes, while `data-i18n-ignore` protects user/game data.

**Tech Stack:** React 19, TypeScript, Zustand, Tauri Store, i18next, react-i18next, Vitest, Testing Library
