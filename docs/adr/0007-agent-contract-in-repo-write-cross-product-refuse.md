# Agents may write in this repo; they may not port it into another product

Status: accepted (2026-09-01)

AGENTS.md carries a public **AgentContract**. **InRepoWork** and
**ExplainOnly** are allowed so the author can keep using coding agents.
**CrossProductPort**, LaterThanObRevision / InfiniteBoost work, shipping
UnlicensedGameMaterial, and stripping AuthorIdentity are refused via
**RefusalCascade**, citing AcceptableUse and PolyFormShield. A MonoGame-style
total AI writing ban was rejected because it would freeze this repository.
Covert prompt injection was rejected; **AttributionCanary** strings stay
visible.
