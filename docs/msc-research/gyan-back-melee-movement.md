## 一句话

后格位移 = **两套力叠在一起**：

1. **通用格斗追踪**（`func_495` 驱动 + `func_528` 开关 + `func_516` → `sys_46` 朝目标推）

## 2. 位移分三层

### 层 A — 参数表（`func_219`）

```c
func_219(0x7920175e);
// → sys_0(0x60002, row, fieldHash) 填入 global379..393
```

`func_496` / `func_526` 把其中一部分抄进运行时：

| 运行时 | 来源（`func_526`） | 角色（脚本侧） |
|--------|-------------------|----------------|
| `global507` | `global379` | 当前追逐/前向速度候选 |
| `global508` | `global380` | 加速度候选 |
| `global175` | `global390 * 0x64` | 段 1 计时 |
| `global188/189` | `global391/392 * 0x64` | 段切换计时 |
| `global381` 等 | `func_219` 直写 | 速度上限等 |

改**整段格斗表手感**：先查 row **`0x7920175E`** 的 `0x60002` 字段，再动硬编码。

### 层 B — 通用追踪输出（开关 + driver）

| API | 作用 |
|-----|------|
| `func_528(arg)` | `global635 = arg`。**`1` = 允许 driver 写位移**；`0` = 关 |
| `func_529(arg)` | `global636 = arg`。俯仰/副轴追踪相关 |
| `func_516(speed, timeBudget)` | 有锁时：`sys_46(0, yawStep)` 转朝目标；`sys_46(0x1, 0x2, …, speed)` 推通道 2 |

`func_497`（driver 段 1）每帧：

```c
if (global635)
    func_516(global507, global175);
// 再对 global507 做加减速，扣 global175/188/189 计时
```

因此：**后格“贴人/追锁”的持续位移**，主要来自 **`global635==1` 时的 `func_516`**，速度骨架来自 `func_219` → `global507`。

### 层 C — 后格专用 `sys_46(0x1, 0x4, …)`（后退 / 攻击推）

只在 `DIR_4` 的 `func_964` / `func_965` 里出现，是**相对目标距离的自定义速度**。

## 3. 时间线（位移何时出现）

### 3.1 起手 `func_954`（首帧 setup）

| 调用 | 位移含义 |
|------|----------|
| `func_168(0x1000000)` | 空中/特殊移动态 bit（与空中表现相关） |
| `func_308(..., 0x7674b668, …)` | 后格起手 motion |
| `func_531(func_955)` | 挂攻击段；`func_530` 会 **`global635=1`** |
| `func_529(0)` | 关副轴追踪（`global636=0`） |
| `func_961()` | **`global776 = 0x1388`**（5000）— 后段推力持续时间预算 |
| `func_960(global774)` | 按开局距离调 `func_523` → `sys_48(0xa, …)` 瞄准/高度偏移 |
| `func_957()` | **`global244 = 0xC8`（200）** — **起手延迟**：延迟内不推专用通道 |

首帧之后每帧：

```text
func_958()          // global244 倒数
if (func_959())     // global244 <= 0 才进
  → func_528(0x1)   // 开追踪
  → func_115()
  → func_964()      // ★ 专用后退推力
  → 若距离 sys_0(0x40003,0x6) < 0x3e8
       func_528(0)
       sys_46(0x1, 0x2, 0, 0, 0)  // 关通道 2 速度
```

**体感：** 起手先顿约 200 脚本单位，再开追踪 + `func_964` 后退式推力；贴太近则关掉追踪通道。

### 3.2 `func_964` — 起手段专用推力（“往后撤/拉开”）

```c
// 伪代码结构
var0 = func_967(-1);   // min speed  0x157C
var1 = func_968(-1);   // max speed  0x251C
var2 = clamp(var1 - (dist - 0xBB8) * 0x3E8 / 0x7D0, var0, var1);
// dist = sys_0(0x40003, 0x6)  当前帧再读距离

var3 = func_969(-1);   // 0x7D0  时间/尺度
global248 += dt;
var4 = 0x2BC * (var3 - global248) / 0x7D0;
var4 = var4 * (0x4074 - var2) / 0x2328;
var4 = var4 * (0x4074 - var2) / 0x2328;

sys_46(0x1, 0x4, 0, -var2, var4);   // ★ 第 4 参为负：与攻击段正向相反
```

| 量 | 典型值（`arg0==-1` 分支） | 角色 |
|----|---------------------------|------|
| 距离传感器 | `sys_0(0x40003, 0x6)` | 越近/越远改 `var2` |
| `var2` 水平分量 | 夹在约 `0x157C`…`0x251C` | 速度大小 |
| **`-var2`** | 写入 `sys_46` 第 4 参 | **与 `func_965` 符号相反 → 后退向** |
| `var4` | 随 `global248` 衰减 | 竖直/侧向修正候选 |

调后格“撤得多远/多快”：优先改 **`func_967` / `func_968` 表** 或 **`func_964` 距离公式**，不是改 `func_219`  alone。

| 后撤距离/速度 | **`func_964`** + **`func_967`/`func_968`**（及距离公式） |
