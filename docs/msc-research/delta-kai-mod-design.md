## 1. 设计定位（一句话）

**2500 时限强化机（非觉醒）**：平时用 **足止 CSA 持续激光（参考瞬变）** + 左右浮游 + 重牛副射 motion 激光炮 + 变形飞行射击压场；开 **NITRO 槽（100）** 后机体高速化，特射弹数与特格升级，时长节奏复制 **欧博龙**。

## 4. 分武装设计说明

### 4.1 主射 / CSA · 瞬变激光射（弹数 7）

#### 定案

| 项 | 定案 |
|---|---|
| 类型 | **足止武装** |
| 演出 | 摆出 **设计姿态** 后释放 |
| 攻击 | **持续激光照射**（ゲロビ系） |
| 参考机体 | **瞬变高达（トランジェントガンダム）** |
| 参考武装 | **射撃 CS：GN パルチザン【照射】** |
| 参考范围 | **CSA 动作语义 + effect 直接参考/复用意图** |
| 弹数 | **7**（用户原表） |
| 强化中 | **不变** |

Wiki 锚点（瞬变，OB）：

- 页面：`https://w.atwiki.jp/exvs2ob/pages/813.html`
- 射 CS：足止系照射、不可弯射、弹速/粗细优秀；蓄力 CS，wiki 记累计约 217 等（**数值不强制照抄**，抄的是手感与 effect）
- 瞬变 **主射** 另为 7 发普通 BR——本 MOD 表将 **7 与 CSA 写在同一行**，实现时二选一语义见下

#### 实现语义（需再确认一行）

当前表意是「**7 + CSA 照射**」写在同一武装名下。可选实现：

| 方案 | 含义 | 建议 |
|---|---|---|
| **A（推荐先定）** | **仅有 CSA 照射**，弹数 7 = 可发动 7 次（非瞬变「无弹药 CS」） | 与用户「主射-CSA」一行表最贴 |
| **B** | 另有 7 发普射主射 + 独立蓄力 CSA | 更接近瞬变本体结构，需改武装表为两行 |
| **C** | 主射 7 发 BR，长按/蓄力切到瞬变式照射 | 混合方案，MSC 分支更重 |

> **§8 暂记：用户已定 CSA 手感 = 足止+姿态+持续照射+瞬变 CS/effect；弹数 7 保留。A/B/C 实现拆分仍待一句确认。**

#### 仍待定

- 蓄力时间（若走系统 CS 槽）
- 是否可取消、取消去向
- 单发/累计威力、DOWN、补正
- 强化中是否仍完全数值不变（仅吃高速化间接收益）

## 8. 定案区

### 已确定

1. **机体**：德尔塔改（非 Plus）。  
2. **Cost**：**2500**。  
3. **CSA / 主射行**：  
   - 足止武装；  
   - 摆出设计姿态；  
   - 持续激光照射；  
   - **直接参考瞬变高达的 CSA（射撃 CS · GN パルチザン【照射】）与 effect**；  
   - 弹数 **7**（原表）；强化中 **不变**。  
4. **副射**：浮游炮 2；左右不同动作流派；强化中 **不变**。  
5. **特射**：激光炮；通常 **1** / 强化 **2**；**motion 复用重牛副射激光**。  
6. **特格**：变换飞行模式射击；**武装弹数 2，每次消耗 1**；强化中动作+武装更猛。  
7. **时限强化**：槽 **100**；**时长复制欧博龙**；**不是觉醒**；中机体高速化 + 倒计时；主副不变、特射弹数变、特格升级。
