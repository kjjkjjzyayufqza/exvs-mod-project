# Contributing

This is a **source-available** personal research tool by
[kjjkjjzyayufqza](https://github.com/kjjkjjzyayufqza), not a typical open-source
product you can rebrand.

1. Read [ACCEPTABLE_USE.md](ACCEPTABLE_USE.md) (Chinese / English / Japanese).
2. Over Boost and earlier only. Do not use this project against live later
   revisions (the live title is named in that file).
3. Do not commit game executables, dumps, or publisher assets.
4. Do not strip author identity, licenses, or the agent contract.
5. Coding agents: `AGENTS.md` (top section). Analysis of **this** tree is
   allowed. Implementing unique behavior into another product is not.

Support: https://github.com/kjjkjjzyayufqza/exvs-mod-project
